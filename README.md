# Learning Theories Timeline

Interactive static visualization of learning theory and instructional design milestones.

## GitHub Pages Deployment

This project is ready to deploy through GitHub Actions.

1. Push this folder to a GitHub repository on the `main` branch.
2. Open the repository on GitHub.
3. Go to `Settings` -> `Pages`.
4. Set the Pages source to `GitHub Actions`.
5. Push to `main` or run `Deploy GitHub Pages` manually from the `Actions` tab.

The workflow publishes only `index.html`, `styles.css`, `app.js`, and `.nojekyll`.
